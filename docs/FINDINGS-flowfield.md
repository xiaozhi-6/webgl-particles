# 流场笔记：把一个"好看的运动"做对，比想象中难

> 这份文档记录了一个失败率很高的过程 —— 为了让粒子云有流体感，我试了 9 轮，
> 每一轮都被真实用户用肉眼发现"还是不对"。
>
> **写下来是因为其中的几条结论反直觉，而且有明确的数学解释。**

如果你只想看结论，跳到 [结论汇总](#结论汇总)。

---

## 一、五个反直觉的结论

### 1. 静态的散度为零流场**不会**混合

**第一直觉**：粒子聚成线是因为速度场"可压缩"。改成无散度（保面积）就好了。

**实测**：更糟。

| 帧 | 静态无散度场 | 方向场（可压缩） |
|---|---|---|
| 300 | 变异系数 2.223 | 聚成线 |
| 1200 | **6.488** | 聚成线 |
| 3000 | **7.150**（持续恶化） | 聚成线 |

**原因**：**二维静态散度为零场是哈密顿系统，它不混合。**
保面积只保证"相空间"面积不变，不保证粒子在物理空间铺开 ——
粒子会被困在**不变流形 / KAM 环面**上，结果是**分层**而非混合。

**混洗需要时间相关的流场（chaotic advection）。**

---

### 2. 周期随八度数**指数**增长

**现象**：流场看起来像 GIF 循环。

**原因**：`sin(q.x*1.000 + t*0.370)` 这类频率是有限小数（有理数）。
**任意有限个有理数频率之和必然有公周期** —— 周期 = 各周期的最小公倍数。

**修法**：频率取**互不可通约**的值（√2 / √3 / √5 / 黄金比），并叠加多个八度。

```glsl
const float G  = 1.6180340;
const float R2 = 1.4142136;
s += 1.00 * sin(q.x*1.000 + t*0.370*G) * cos(q.y*1.000 - t*0.290*R2);
s += 0.42 * cos(q.x*2.100*R2 - q.y*1.700*G - t*0.410*R5);
```

**N 个八度的联合周期 ≈ ∏ Tᵢ** —— 指数级增长，**这是单八度原理上做不到的**。

**自相关验证**（密集连拍 30 帧 @150ms，做 lag 扫描）：

| 版本 | lag=10 (1.50s) | 判定 |
|---|---|---|
| curl noise | **0.566**（孤立尖峰） | 1.5 秒周期 |
| psi 单八度 | 0.293 | 无峰值但整体偏高 |
| **psi 多八度** | **0.025** | ✅ 无周期 |

★ **孤立尖峰 = 周期性；平滑衰减 = 无短周期。** 两者容易混淆，必须看曲线形状。

---

### 3. 均匀平移**也是**无散度的 —— 这解释了"像被风吹"

**现象**：参数调小时，整个画面朝一个方向漂移。

**原因**：流函数 ψ 的旋度给出速度。**当空间频率很低时，屏幕只覆盖 ψ 的一个很低频区域，
而低频区域的旋度近似是均匀的。**

**而 `v = 常数` 满足 ∇·v = 0** —— 它符合无散度约束，但观感就是风。

> **无散度只保证"不聚集成块"，不保证"流线弯曲"。**

**修法**：加一个以画布中心为心的基础旋转分量。

| 指标 | 修改前 | 修改后 |
|---|---|---|
| 方向一致性（1.0=始终同向） | **+0.374** | **−0.538** |
| 重心净位移 | 273.5 px | **9.8 px** |
| >20 亮度占比 | 0.35% | **27.84%** |

**方向一致性变成负值 = 重心在打转。而且这一个改动同时解决了"结块"。**

---

### 4. 视觉参数必须标定到**粒子间距**的量级

**现象**：调"流场尺度"看不出任何变化；调低粒子数后只剩几个点。

**原因**：算一下就知道 ——
主导波长 = `2π/k`，粒子平均间距 = `sqrt(画布面积/粒子数)`。

| 粒子数 | 流场波长 | **波长/间距** | 观感 |
|---|---|---|---|
| 200,000 | 1872.7 px | **1022×** | 近似均匀雾（旋钮失效） |
| 20,000 | 592.2 px | 102× | 偏粗 |
| 20,000 (scale=3) | 197.4 px | 34× | 条纹清晰 |

**波长是间距的 341~1022 倍 —— 结构比粒子粗太多，画面就是一团雾。**

**修法**：把基准波长标定到间距的约 30 倍（`BASE_NORM = 0.17`），并让它跟随粒子数缩放。

**验证**（粒子数变化时的铺开度）：

| 粒子数 | >20 亮度占比 |
|---|---|
| 200,000 | 26.49% |
| 50,000 | 26.37% |
| 20,000 | 26.07% |

**覆盖率几乎不随粒子数变化。**

★ **这本来是一个可以手算出来的量。** 我调了很多轮才想到去算它。

---

### 5. 力的单位与位移缩放必须一致

**现象**（在新 demo 里）：粒子完全随机化，鼠标跟随看不出效果。

**原因**：力已经是"每帧"量（阻尼 `v *= 0.94`），位移却又乘了 60：
```glsl
p += v * u_dt * 60.0;      // vavg 收敛到 ~20，每帧移动 ~20px ≈ 1200 px/s
```

**修法**：把速度上限锁住 + 力度整体下调。

```glsl
v *= 0.94;
float vmag = length(v);
if (vmag > 6.0) { v *= 6.0 / vmag; }
```

**修后**：`vavg` 从 19.7 降到 0.7~3.8，跟随立即可见。

## 三、结论汇总

| 结论 | 说明 |
|---|---|
| **静态无散度场不混合** | 粒子困在不变流形上，结果是分层不是混合 |
| **周期随八度数指数增长** | 消除可见周期最有效的手段 |
| **均匀平移也是无散度的** | 低频旋度近似均匀 → "风感"；需要旋转分量 |
| **视觉参数按粒子间距标定** | 用绝对屏幕尺度做基准在不同粒子数下都会失效 |
| **力的单位要与位移缩放一致** | 否则速度失控，一切运动被随机化淹没 |
| **无散度 ≠ 混沌** | 保面积保证不聚集，不保证轨迹杂乱 |

## 四、方法学：怎么"看见"运动

**这件事我做得很晚，而它是最关键的。**

| 工具 | 作用 |
|---|---|
| **密集连拍** | 间隔 150ms 抓 30~40 帧。★ 间隔必须**远小于**待测周期，否则相位混叠会完全掩盖周期性 |
| **时间自相关** | lag 扫描。**孤立尖峰 = 周期；平滑衰减 = 无周期** |
| **重心漂移方向一致性** | 量化"风感"（1.0 = 始终同向） |
| **邻域解相关** | 取初始距离 < 8px 的粒子对，看 400 帧后的平均距离。**比值 ≈ 1 = 沿轨道；≫1 = 像热运动** |
| **页面检查 + 运行检查** | 前者读 `window.__ready` 与异常，后者读帧率/CPU/输出有效性。**只跑后者会漏掉"页面根本没起来"** |

★ **两个我设计错的指标（都被真实用户推翻）：**

| 我报告的 | 用户看到的 | 指标错在哪 |
|---|---|---|
| "覆盖率 26.49%，粒子数不影响密度" | **"还是会散"** | 粒子少 10 倍，间距只涨 3.2 倍；覆盖率不反映稀疏感 |
| "扰动/平流 = 192 倍，必然可见" | **"看不出扰动"** | 扰动是单帧位移，流场下一帧就抹掉；静态比值测不出动态可感知性 |

**统计量不能替代眼睛。这句话我用了 9 轮才真正理解。**

## 五、当前实现

`demo/flowfield.html` 采用的是**多八度时变流函数 + 基础旋转分量**：

```glsl
float psi(vec2 q, float t) {
  const float G = 1.6180340, R2 = 1.4142136, R3 = 1.7320508, R5 = 2.2360680;
  float s = 0.0;
  s += 1.00 * sin(q.x*1.000 + t*0.370*G) * cos(q.y*1.000 - t*0.290*R2);
  s += 0.62 * sin(q.x*1.730 + q.y*1.210 + t*0.530*R3);
  s += 0.42 * cos(q.x*2.100*R2 - q.y*1.700*G - t*0.410*R5);
  s += 0.28 * sin(q.x*1.400*R3 + q.y*2.300*R2 + t*0.330*G*R2);
  s += 0.17 * cos(q.x*3.100*R5 + q.y*2.600*G - t*0.250*R3);
  s += 0.10 * sin(q.x*4.300*G - q.y*3.700*R2 + t*0.190*R5);
  return s;
}

vec2 v = vec2(dpy, -dpx);                                   // ψ 的旋度 -> 无散度
v += vec2(-d0.y, d0.x) / max(dot(d0,d0), 1.0) * (S*S*0.11);  // 基础旋转，消除风感
```

**已验证**：60fps、CPU 0.0 ms、自相关 0.025（无周期）、方向一致性 −0.33（无风感）、铺开度 26.5%。

**已知未解决**：在极低粒子数（< 2 万）下，肉眼仍会感觉偏稀 —— 覆盖率指标不反映这一点，
需要靠点大小补偿而不是靠流场波长。
