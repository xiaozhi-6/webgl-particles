# 一个真实的修复：四边形扩边 0.5 像素

> 这是整个研究里**唯一一个被端到端验证、并且真正改善了画质的改动**。
> 记录完整证据链，因为它同时也是一个"我差点把自己的测量装置当成结论"的案例。

---

## 一、问题

实例化四边形的顶点是：

```glsl
vec2 pos = a_center + a_corner * a_rad;
```

四边形**恰好只覆盖 ±a_rad**。落在圆周上的片元正好位于四边形边界，按填充规则
（`gl_Position` 落在边界上的片元不被光栅化）会丢掉一整圈边缘覆盖率。

## 二、修复

```glsl
float ext = 0.5;
vec2 pos = a_center + a_corner * (a_rad + ext);
// v_local 保持「±1 对应 a_rad」的语义
v_local = a_corner * (a_rad + ext) / a_rad;
```

扩 0.5 与 1.0 的实测结果**完全相同**，说明收益来自「让边缘片元被光栅化」，
而不是「多覆盖多少」。取 0.5 作为最小改动。

**顶点数不变（仍是 4 个），无性能开销。**

## 三、证据链（三个独立装置）

### 装置 1：洁净合成对照（同装置内生成 Canvas2D 参考）

同一份点云、同一几何、只有 `ext` 不同：

| 方案 | 平均 alpha | 平均亮度 | vs Canvas2D 亮度差 | >10 占比 |
|---|---|---|---|---|
| **Canvas2D 参考** | **252.5715** | 120.07921 | — | — |
| ext = 0（原状） | 252.0437 | 120.47862 | **1.65177** | 2.419% |
| **ext = 0.5** | **252.3740** | 120.54865 | **1.44376** | **1.601%** |
| ext = 1.0 | 252.3741 | 120.54870 | 1.44372 | 1.601% |

**改善 12.6%**，且 alpha 更接近 Canvas2D。

### 装置 2：真实生产页面，宽屏 1440×900 dpr 1（不饱和路径）

| 方案 | 平均 alpha | 亮度平均差 | 最大差 | >10 占比 |
|---|---|---|---|---|
| **Canvas2D** | **252.8900** | — | — | — |
| ext = 0 | 252.4768 | 0.77429 | 141.2 | 2.454% |
| **ext = 0.5** | **252.7560** | **0.54266** | **84.5** | **1.565%** |

**改善 29.9%。** 分子集：

| 子集 | n | ext=0 | ext=0.5 | 改善 |
|---|---|---|---|---|
| 饱和（alpha ≥ 250） | 188,927 | 0.40809 | **0.21539** | **−47.2%** |
| 未饱和（< 240） | 3,888 | 17.66420 | **15.74733** | −10.9% |

### 装置 3：生产代码路径最终验收（1440×900 dpr 1）

改到 `main.js` 之后重新测：

```
内容像素          : 193,661
Canvas2D 平均alpha: 252.8900
```

与装置 2 的 `ext=0.5` 数值**完全一致**，说明改动按预期生效。

## 五、一个必须记下来的教训

我第一次做这个实验时，得出的结论是「**扩边改善 12%**」—— 但那个装置
（`shader-base.html` 系列）**本身是坏的**：

```js
ctr[k*2] = (j1*0 + 1) * (offX + (bx[k]-0.5)*scale);   // j1*0+1 是无意义的
var radius = dot * 1.08;                              // 生产实际是 dot * 0.9
```

**它渲染的是一个几何参数错误的合成图形，不是生产图形。**

而我当时差点就拿它去改线上代码。真正让我停下来的是：**同一个改动在两个装置上
给出矛盾结论**（合成装置 −12%，真实页面 ±0%）。矛盾的装置一定有问题，查下去才
发现是几何参数错了。

**修正后的做法**（装置 1）：把 `buildPoints()` 抽成公共函数，让三种 `ext` 和
Canvas2D 参考**共用同一份点数据、同一几何、同一确定性抖动**，只有 `ext` 一个变量。

**教训**：当一个改动在不同装置上给出矛盾结论时，**不要挑一个相信**，要去查哪个装置错了。
